# WayPoint — short Tech Mela demo script

“Good morning. Our project is WayPoint, an offline navigation concept for places where internet connectivity or GPS may be unreliable, such as trekking areas, forests, and remote locations.

For this prototype, we are demonstrating the idea inside a college using an indoor floor map. A QR code can identify a known checkpoint. The user selects a destination, and WayPoint calculates and highlights a route through the mapped paths.

The map and route data can be stored locally so navigation can continue after the website has been cached. A QR code does not continuously track the user, so larger-area offline maps and automatic positioning are part of our future scope.

Our goal is to explore how people can find their way even when connectivity is unavailable. Thank you.”
